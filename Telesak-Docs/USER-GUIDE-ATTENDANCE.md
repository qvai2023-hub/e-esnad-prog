## 1. مقدمة: كيف يعمل النظام؟

نظام الحضور في **تيلي ساك** مصمَّم ليكون **تامّ التلقائية** — لا تحتاج إلى أيّ إجراء يدوي تقريباً. كل ما عليك هو:

1. ✅ **تسجيل الدخول** → الحضور يُسجّل تلقائياً
2. ✅ **العمل** → النظام يتتبّع نشاطك تلقائياً
3. ✅ **إغلاق المتصفح** أو **تسجيل الخروج** → الانصراف يُسجّل تلقائياً

```
┌────────────────────────────────────────────────────────────┐
│  سجّل دخولك  →  الحضور يُسجّل تلقائياً  →  ابدأ العمل      │
│                                                            │
│  أثناء العمل: النظام يرسل "نبض" كل دقيقة (إثبات نشاط)     │
│                                                            │
│  عند الانتهاء:                                             │
│  ├─ إغلاق المتصفح ← انصراف تلقائي ✓                        │
│  ├─ تسجيل الخروج ← انصراف تلقائي ✓                        │
│  └─ 30 دقيقة بدون تفاعل ← تنبيه → انصراف تلقائي ✓        │
└────────────────────────────────────────────────────────────┘
```

> **النقطة المهمة:** لا تحتاج إلى "الضغط على زر الحضور" — كل شيء يحدث في الخلفية.

## 2. تسجيل الحضور — تلقائي بالكامل

### متى يُسجّل الحضور؟

| الحالة | هل يُسجّل حضور؟ | ملاحظة |
|--------|---------------|--------|
| **تسجيل دخولك كموظف** | ✅ نعم | تلقائي — لا يحتاج أي إجراء |
| **تسجيل دخولك كمشرف** | ❌ لا | المشرفون لا يُسجَّل حضورهم |
| **تسجيل دخولك كـ Admin** | ❌ لا | مدير المنصة لا يُسجَّل حضوره |
| **تسجيل دخولك مرتين بنفس اليوم** | ✅ نعم (سجل جديد) | إذا كان السجل الأول مُغلقاً |

### أين يُحفظ الحضور؟

النظام يُنشأ سجلاً في قاعدة البيانات يحتوي على:
- 🕐 **وقت الحضور** — لحظة تسجيل الدخول
- 🕐 **آخر نبض** — يتجدد كل دقيقة
- ⬜ **وقت الانصراف** — فارغ حتى تُغلق الجلسة

> **هل يمكنني رؤية وقت الحضور؟** نعم — في تقرير الحضور (انظر القسم 7).

## 3. النبض (Heartbeat) — إثبات النشاط

### ما هو النبض؟

كل **60 ثانية** (دقيقة واحدة)، يرسل النظام إشارة صغيرة إلى الخادم تقول: **"الموظف لا يزال يعمل"**.

```
الموظف يعمل ← النظام يرسل نبض كل دقيقة ← الخادم يُحدّث السجل
     ↓
إذا توقف النبض 15 دقيقة ← النظام يُسجّل انصرافاً تلقائياً
```

### لماذا النبض مهم؟

| السبب | الشرح |
|-------|-------|
| **إثبات النشاط** | يُثبت أنك لا تزال تعمل |
| **تجنب الانصراف المبكر** | يمنع النظام من تسجيل انصرافك بالخطأ |
| **حساب دقيق** | يُساعد في حساب وقت الانصراف بدقة إذا أغلقت المتصفح فجأة |

### هل يؤثر النبض على سرعة النظام؟

**لا على الإطلاق.** النبض إشارة صغيرة جداً (بضع بايتات) لا تُبطئ النظام أو تستهلك بيانات.

> **يمكنك التحقق:** افتح `F12` → Network → ستُرى طلب `LogActivity` كل دقيقة.

## 4. تسجيل الانصراف — 3 طرق

### الطريقة 1: إغلاق المتصفح (الأكثر شيوعاً) 🏠

```
أنت تعمل → أغلقت التاب أو المتصفح → النظام يُسجّل انصرافك تلقائياً
```

**كيف يعمل:**
- عند إغلاق المتصفح، يرسل النظام إشارة خاصة (`sendBeacon`) تُخبر الخادم بوقت آخر نشاطك
- وقت الانصراف = **آخر نبض مسجّل** (أكثر دقة من "الآن")
- ✅ **يعمل حتى لو انقطع الإنترنت للحظة**

> **ملاحظة:** إذا نقرت على رابط خارجي (مثل WhatsApp)، يُسجَّل انصرافك أيضاً. لكن التنقل داخل النظام (مثل فتح المهام أو التقارير) **لا يُسجّل انصرافاً**.

---

### الطريقة 2: تسجيل الخروج (Logout) 🚪

```
اضغط على اسمك في الأعلى ← اختر «تسجيل الخروج» → انصراف تلقائي
```

**كيف يعمل:**
- تسجيل الخروج يُسجّل انصرافك فوراً
- وقت الانصراف = وقت الضغط على «خروج»
- ✅ **الطريقة الأكثر أماناً** — تضمن عدم وجود أي سجل مفتوح

---

### الطريقة 3: الانصراف التلقائي بعد الخمول ⏰

```
أنت لم تتفاعل 30 دقيقة → تظهر نافذة تنبيه (5 دقائق) → إذا لم تستجب → انصراف تلقائي
```

**الجدول الزمني:**

| الوقت | الحدث |
|-------|-------|
| دقيقة 0 | تسجيل الدخول |
| دقيقة 30 | تظهر نافذة: «هل تريد الاستمرار؟» (عدّاد 5:00) |
| دقيقة 30-35 | يمكنك الضغط «نعم» للاستمرار |
| دقيقة 35 | إذا لم تضغط شيئاً → انصراف تلقائي |

**النافذة تبدو هكذا:**

```
┌─────────────────────────────────────────┐
│  ⚠️ انتهاء الجلسة قريباً               │
│                                          │
│  ستنتهي جلستك تلقائياً خلال: 05:00      │
│  هل تريد الاستمرار؟                     │
│                                          │
│  [ ✅ نعم ]        [ ❌ لا ]             │
└─────────────────────────────────────────┘
```

| الضغط | النتيجة |
|-------|--------|
| **نعم** | النافذة تختفي، المؤقت يُعاد ضبطه 30 دقيقة جديدة |
| **لا** | انصراف فوري، يُحوّل إلى صفحة تسجيل الدخول |
| **لا شيء** (5 دقائق) | انصراف تلقائي، يُحوّل إلى صفحة تسجيل الدخول |

> **مهم:** لا يمكن إغلاق النافذة بالنقر خارجها — يجب الاختيار بوعي.

---

### الطريقة 4: الحماية من الخادم (Safety Net) 🛡️

```
إذا حدث أي شيء غير متوقع (متصفح يتجمد، كمبيوتر يُغلق، بطارية نفدت)
→ الخادم يُسجّل انصرافك خلال 15 دقيقة
```

**كيف يعمل:**
- الخادم يُراقب كل سجل مفتوح
- إذا توقف النبض لـ **15 دقيقة** → يُسجّل انصرافاً تلقائياً
- وقت الانصراف = **آخر نبض معروف** (أكثر دقة)
- يُعلَّم السجل بـ «انصراف تلقائي» (AutoCheckout)

> **لماذا 15 دقيقة؟** لأن النبض يُرسل كل دقيقة — 15 دقيقة تعني أن النظام متأكد تقريباً أن الجلسة انتهت.

## 5. نافذة التنبيه — عند عدم النشاط

### متى تظهر؟

تظهر نافذة التنبيه إذا لم تتفاعل مع النظام لـ **30 دقيقة** متواصلة. يُعتبر «تفاعلاً» أي من:
- النقر (click)
- الكتابة (keypress)
- تحريك الفأرة (mousemove)
- التمرير (scroll)
- اللمس على الموبايل (touch)

### ماذا يحدث إذا ظهرت وأنا أشاهد التقرير؟

إذا كنت تنظر إلى التقرير فقط بدون أي تفاعل (لا نقر، لا تمرير) → ستظهر النافذة. اضغط **«نعم»** للاستمرار.

### هل يمكنني إغلاق النافذة بالنقر خارجها؟

**لا.** النافذة مصمَّمة لتبقى ظاهرة حتى تختار:
- ✅ «نعم» — استمرار العمل
- ❌ «لا» — تسجيل الخروج
- ⏰ انتظر 5 دقائق — انصراف تلقائي

## 6. كيف تُحسب ساعات العمل؟

### المعادلة البسيطة

```
ساعات العمل = وقت الانصراف − وقت الحضور
```

**مثال:**
| الحدث | الوقت |
|-------|-------|
| تسجيل الحضور | 08:00 ص |
| تسجيل الانصراف | 04:30 م |
| **المدة** | **8 ساعات و 30 دقيقة** |

### حالة خاصة: لم أُسجّل انصرافاً

إذا كان سجل الحضور مفتوحاً (لا يوجد وقت انصراف) → يظهر في التقرير:

```
وقت الانصراف: لم يُسجل
```

هذا يعني أن السجل مفتوح — إما أنك لا تزال تعمل، أو أن الجلسة أُغلقت تلقائياً ولم يتم تحديث العرض بعد.

### حالة خاصة: العمل لساعة متأخرة (عبور منتصف الليل)

إذا بدأت العمل في 10 مساءً وانتهيت في 2 صباحاً → النظام يُقسّم السجل تلقائياً:

| اليوم | وقت الحضور | وقت الانصراف | المدة |
|-------|------------|-------------|-------|
| اليوم 1 | 22:00 | 23:59:59 | 1 ساعة 59 دقيقة |
| اليوم 2 | 00:00:00 | 02:00 | 2 ساعات |

> **لماذا التقسيم؟** لأن تقرير الحضور يُجمّع البيانات حسب اليوم — التقسيم يضمن حساب صحيح لكل يوم.

## 7. تقرير الحضور

### كيف أستخرج تقريري؟

**للموظف:**
1. اذهب إلى «التقارير» → «تقرير الحضور والانصراف»
2. اختر الفترة (من — إلى)
3. اختر نوع التقويم (ميلادي أو هجري)
4. اضغط «استخراج التقرير»

**للمشرف:**
1. اذهب إلى «التقارير» → «تقرير الحضور والانصراف»
2. اختر الشركة والموظف (اختياري)
3. اختر الفترة
4. اضغط «استخراج التقرير»

### ما يُعرض في التقرير

| العمود | الوصف | مثال |
|--------|-------|------|
| **التاريخ** | يوم العمل | 15/01/2026 |
| **اليوم** | اسم اليوم | الأربعاء |
| **الحضور** | وقت تسجيل الدخول | 08:00 |
| **الانصراف** | وقت الانصراف | 04:30 |
| **عدد الساعات** | المدة الكلية | 8:30 |

> **إذا لم يُسجّل انصراف** → يظهر «لم يُسجل» في عمود الانصراف.

## 8. الأسئلة الشائعة

### ❓ هل يجب أن أضغط على زر "حضور" عند الدخول؟

**لا.** الحضور يُسجّل تلقائياً عند تسجيل الدخول. لا يوجد زر "حضور" في النظام.

---

### ❓ ماذا إذا نسيت تسجيل الخروج؟

**لا مشكلة.** إذا أغلقت المتصفح → انصراف تلقائي. إذا بقيت مسجلاً دخول → النظام يُسجّل انصرافك بعد 30+5 دقائق من الخمول. إذا حدث شيء غير متوقع (تجمّد المتصفح) → الخادم يُغلق السجل خلال 15 دقيقة.

---

### ❓ هل يمكنني تعديل وقت الحضور أو الانصراف؟

**لا.** الأوقات تُسجّل تلقائياً من النظام ولا يمكن تعديلها يدوياً. إذا كان هناك خطأ (مثلاً انصراف مبكر بسبب مشكلة تقنية)، تواصل مع المشرف.

---

### ❓ ماذا إذا فتحت تيلي ساك على جهازين في نفس الوقت؟

النظام يُنشئ سجل حضور واحد فقط لليوم. إذا كان لديك سجل مفتوح وفتحت على جهاز آخر → النظام يستمر في نفس السجل ويُحدّث النبض. لا يُنشأ سجل مزدوج.

---

### ❓ هل يؤثر إغلاق التاب على عملي؟

**لا.** إذا أغلقت التاب ولم تُنهِ عملك → يُسجّل انصرافك. يمكنك تسجيل الدخول مرة أخرى واستكمال العمل — سجل جديد سيُنشأ للجلسة الجديدة.

---

### ❓ لماذا يظهر لي "تم تسجيل الخروج تلقائياً"؟

هذا يعني أن النظام أغلق جلستك لأنك لم تتفاعل لـ 35 دقيقة (30 دقيقة + 5 دقائق تنبيه). سجّل دخولك مرة أخرى إذا كنت ترغب في الاستمرار.

---

### ❓ هل يمكنني الاستمرار في العمل بعد ظهور نافذة التنبيه؟

**نعم.** اضغط **«نعم»** — النافذة تختفي ويُعاد ضبط المؤقت 30 دقيقة جديدة. يمكنك الاستمرار في العمل.

---

### ❓ ماذا عن العمل لساعة متأخرة؟

إذا عملت بعد منتصف الليل (مثلاً من 10 مساءً إلى 2 صباحاً) → النظام يُقسّم السجل تلقائياً إلى يومين. تقرير الحضور يُظهر كل يوم على حدة.

---

### ❓ هل المشرف يُراقب الحضور لحظياً؟

المشرف يمكنه استخراج تقرير الحضور لأي فترة. التقرير يُظهر جميع سجلات الحضور والانصراف للموظفين.

---

### ❓ لماذا لا يُسجَّل حضور المشرف؟

نظام الحضور مصمَّم للموظفين فقط. المشرفون (Company) ومديرو المنصة (Admin) لا يُسجَّل حضورهم لأن النظام يُركّز على تتبّع وقت عمل الموظفين المُسنَّد إليهم المهام.

```
┌────────────────────────────────────────────────────────────┐
│                    🟢 تسجيل الدخول كموظف                    │

│              ✅ الحضور يُسجّل تلقائياً                      │
│                         ↓                                    │
│         💓 النبض كل دقيقة (إثبات النشاط)                   │
│                         ↓                                    │
│    ┌────────────────────┼────────────────────┐              │
│    ↓                    ↓                    ↓              │
│ تسجيل الخروج      إغلاق المتصفح      30 دقيقة خمول        │
│    ↓                    ↓                    ↓              │
│ ✅ انصراف        ✅ انصراف         ⚠️ تنبيه (5 دق)         │
│                                              ↓              │
│                                    ✅ انصراف تلقائي       │
│                                              ↓              │
│                                    🚪 تحويل للدخول         │
└────────────────────────────────────────────────────────────┘
```

### الجدول الزمني للنظام

| الوقت | الحدث | من يتحكم؟ |
|-------|-------|----------|
| 0:00 | تسجيل الحضور | النظام (تلقائي) |
| كل 1:00 | نبض (Heartbeat) | النظام (تلقائي) |
| 30:00 | نافذة التنبيه | النظام (تلقائي) |
| 35:00 | انصراف تلقائي (إذا لم تستجب) | النظام (تلقائي) |
| متغير | إغلاق المتصفح | أنت (انصراف تلقائي) |
| متغير | تسجيل الخروج | أنت (انصراف فوري) |
| كل 15 دقيقة | فحص الخادم للسجلات المُهملة | النظام (تلقائي) |
