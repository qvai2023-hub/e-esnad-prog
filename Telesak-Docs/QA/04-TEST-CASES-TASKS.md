## ثالثاً: واجهة برمجة التطبيقات — التعليقات والمرفقات (API)

### TC-API-COM-001: جلب تعليقات مهمة (GET)

| البند | التفاصيل |
|-------|----------|
| الوصف | جلب جميع تعليقات مهمة معروفة الـ ID |
| الطلب | `GET /api/v1/tasks/{id}/comments` مع Bearer Token |
| النتيجة المتوقعة | 200 + مصفوفة `data` مرتبة من الأقدم للأحدث، كل عنصر يحتوي على `commentId`, `authorName`, `authorType`, `body`, `createdAt` |
| الأولوية | عالية |

| النتيجة المتوقعة | 404 + `code: "TASK_NOT_FOUND"` |
| الأولوية | عالية |

| الطلب | `GET /api/v1/tasks/{anyTaskInCompany}/attachments` كـ Company |
| النتيجة المتوقعة | 200 + قائمة المرفقات |
| الأولوية | عالية |

---

## الحالات الحدية

- ماذا لو حاول الموظف قبول مهمة تم حذفها بواسطة المشرف في نفس اللحظة؟
- ماذا لو أنهى الموظف مهمة بدون إدخال وقت مستغرق — هل يُسمح؟
- ماذا لو رفع الموظف ملفاً ثم أُعيد إسناد المهمة — هل تنتقل المرفقات؟
- ماذا لو تجاوز عدد المهام المحذودة جماعياً 500؟

---

## رسائل الخطأ المتوقعة

| الحالة | رسالة الخطأ المتوقعة |
|--------|----------------------|
| عنوان فارغ | العنوان مطلوب |
| عنوان مكرر | هذا العنوان موجود مسبقاً |
| تاريخ نهاية خاطئ | تاريخ النهاية يجب أن يكون بعد تاريخ البداية |
| ملف كبير (API) | `FILE_TOO_LARGE` (400) — حجم الملف يتجاوز الحد المحدد |
| بدون ملف (API) | `INVALID_REQUEST` (400) — لم يُرسَل ملف في الطلب |
| تعليق فارغ (API) | `INVALID_REQUEST` (400) — نص التعليق مطلوب |
| مهمة غير موجودة | `TASK_NOT_FOUND` (404) |
| صلاحية محظورة | `TASK_FORBIDDEN` (403) |
