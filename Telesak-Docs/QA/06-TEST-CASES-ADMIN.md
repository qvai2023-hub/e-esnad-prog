## رسائل الخطأ المتوقعة

| الحالة | الرسالة المتوقعة |
|--------|-----------------|
| اسم موظف مكرر | هذا الاسم مسجل مسبقاً |
| إيميل مكرر | هذا البريد الإلكتروني مستخدم |
| رقم جوال مكرر | رقم الجوال مسجل لموظف آخر |
| رقم هوية مكرر | رقم الهوية مسجل مسبقاً |
| تاريخ ميلاد مستقبلي | تاريخ الميلاد غير صحيح |
| اسم مشروع مكرر | هذا المشروع موجود مسبقاً |
| كلمة مرور قديمة خاطئة | كلمة المرور القديمة غير صحيحة |
