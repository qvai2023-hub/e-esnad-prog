# حالات اختبار — التقارير

---

## اسم الميزة: التقارير والإحصائيات (Reports)

### الوصف:
استخراج تقارير المهام والحضور والإحصائيات بفلاتر متعددة.

---

## حالات الاختبار

### TC-RPT-001: فتح صفحة تقرير المهام (مشرف)

| البند | التفاصيل |
|-------|----------|
| الوصف | فتح صفحة إعداد تقرير المهام |
| الخطوات | 1. ادخل كمشرف 2. «التقارير» ← «تقرير المهام» |
| النتيجة المتوقعة | تظهر صفحة الفلاتر: المشروع، الموظف، الحالة، الأولوية، التاريخ |
| الأولوية | عالية |

### TC-RPT-002: استخراج تقرير بفلتر التاريخ

| البند | التفاصيل |
|-------|----------|
| الوصف | استخراج تقرير لفترة زمنية محددة |
| الخطوات | 1. حدد تاريخ البداية: 2026/01/01 2. حدد تاريخ النهاية: 2026/03/31 3. اضغط «استخراج» |
| النتيجة المتوقعة | يظهر تقرير بالمهام التي بدأت في هذه الفترة |
| الأولوية | عالية |

| الأولوية | عالية |

### TC-RPT-011: النص العربي/الإنجليزي المختلط في التقرير

| البند | التفاصيل |

| النتيجة المتوقعة | يظهر النص بالترتيب الصحيح: العربي من اليمين و ChatGPT على اليسار |
| الأولوية | عالية |

| النتيجة المتوقعة | يظهر تقرير بمهام الموظف الحالي فقط (لا يرى مهام غيره) |

## الحالات الحدية

- ماذا لو لم توجد مهام تطابق الفلاتر — هل يظهر تقرير فارغ أو رسالة؟
- ماذا لو حدد فترة طويلة جداً (سنة كاملة) — هل يتحمل النظام؟
- ماذا لو طبع التقرير — هل التنسيق صحيح (RTL)؟
