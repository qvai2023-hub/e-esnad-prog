# حالات اختبار — الحضور والانصراف

---

## اسم الميزة: نظام الحضور والانصراف (Attendance)

### الوصف:
نظام تلقائي لتسجيل حضور وانصراف الموظفين بدون تدخل يدوي، مع تنبيه عند عدم النشاط.

### المتطلبات المسبقة:
- المستخدم مسجل دخول كموظف
- الموظف لديه حضور نشط (تم فتح البرنامج والعمل)

---

## حالات الاختبار

### TC-ATT-001: تسجيل الحضور التلقائي

| البند | التفاصيل |
|-------|----------|
| الوصف | التحقق من تسجيل الحضور تلقائياً عند دخول الموظف |
| الخطوات | 1. سجّل دخول كموظف 2. ابدأ العمل (اقبل مهمة أو تصفح) 3. تحقق من تقرير الحضور |
| البيانات المطلوبة | حساب موظف |
| النتيجة المتوقعة | يظهر سجل حضور جديد بتاريخ ووقت الدخول |
| الأولوية | عالية |

### TC-ATT-002: النبض (Heartbeat) كل دقيقة

| البند | التفاصيل |
|-------|----------|
| الوصف | التحقق من إرسال نبض دوري للخادم |
| الخطوات | 1. سجّل دخول كموظف 2. افتح أدوات المطور (F12) ← تبويب Network 3. انتظر دقيقة 4. راقب الطلبات |
| البيانات المطلوبة | حساب موظف مع حضور نشط |
| النتيجة المتوقعة | يظهر طلب POST إلى `/Attendance/LogActivity` كل 60 ثانية |
| الأولوية | متوسطة |

### TC-ATT-003: تنبيه عدم النشاط بعد 30 دقيقة

| البند | التفاصيل |
|-------|----------|
| الوصف | ظهور نافذة تنبيه بعد 30 دقيقة بدون تفاعل |
| الخطوات | 1. سجّل دخول كموظف 2. لا تلمس الماوس أو لوحة المفاتيح لمدة 30 دقيقة 3. راقب الشاشة |
| البيانات المطلوبة | حساب موظف (يمكن تقليل المدة للاختبار عبر Console: `AttendanceTracker.setConfig({INACTIVITY_WARNING: 10000})`) |
| النتيجة المتوقعة | تظهر نافذة «تنبيه عدم النشاط» مع عدّاد تنازلي (02:00) وزري «استمر في العمل» و «أنهِ العمل» |
| الأولوية | عالية |

### TC-ATT-004: الضغط على «استمر في العمل»

| البند | التفاصيل |
|-------|----------|
| الوصف | إغلاق نافذة التنبيه واستمرار العمل |
| الخطوات | 1. انتظر ظهور نافذة التنبيه 2. اضغط «استمر في العمل» |
| البيانات المطلوبة | نافذة التنبيه ظاهرة |
| النتيجة المتوقعة | تختفي النافذة، يُعاد تشغيل مؤقت الـ 30 دقيقة، الحضور يبقى نشطاً |
| الأولوية | عالية |

### TC-ATT-005: الضغط على «أنهِ العمل»

| البند | التفاصيل |
|-------|----------|
| الوصف | تسجيل الانصراف عبر نافذة التنبيه |
| الخطوات | 1. انتظر ظهور نافذة التنبيه 2. اضغط «أنهِ العمل» |
| البيانات المطلوبة | نافذة التنبيه ظاهرة |
| النتيجة المتوقعة | يتم تسجيل الانصراف، تظهر رسالة تأكيد، ثم يتم التحويل لصفحة الدخول خلال 3 ثوانٍ |
| الأولوية | عالية |

### TC-ATT-006: انتهاء العداد التنازلي بدون استجابة

| البند | التفاصيل |
|-------|----------|
| الوصف | الانصراف التلقائي عند انتهاء الدقيقتين |
| الخطوات | 1. انتظر ظهور نافذة التنبيه 2. لا تضغط أي زر 3. انتظر حتى يصل العداد إلى 00:00 |
| البيانات المطلوبة | نافذة التنبيه ظاهرة |
| النتيجة المتوقعة | يتم تسجيل الانصراف تلقائياً ويُحوّل المستخدم لصفحة الدخول |
| الأولوية | عالية |

### TC-ATT-007: تحريك الماوس أثناء ظهور النافذة

| البند | التفاصيل |
|-------|----------|
| الوصف | التأكد أن تحريك الماوس لا يغلق النافذة |
| الخطوات | 1. انتظر ظهور نافذة التنبيه 2. حرّك الماوس داخل النافذة 3. حرّك الماوس باتجاه أحد الأزرار |
| البيانات المطلوبة | نافذة التنبيه ظاهرة |
| النتيجة المتوقعة | النافذة تبقى ظاهرة ولا تختفي — فقط الأزرار يمكنها إغلاقها |
| الأولوية | عالية |

### TC-ATT-008: الانصراف عند إغلاق المتصفح

| البند | التفاصيل |
|-------|----------|
| الوصف | تسجيل الانصراف عند إغلاق التاب أو المتصفح |
| الخطوات | 1. سجّل دخول كموظف 2. تأكد من وجود حضور نشط 3. أغلق تاب المتصفح 4. تحقق من تقرير الحضور |
| البيانات المطلوبة | حساب موظف مع حضور نشط |
| النتيجة المتوقعة | يُسجّل وقت الانصراف في تقرير الحضور |
| الأولوية | عالية |

### TC-ATT-009: الانصراف عند تسجيل الخروج

| البند | التفاصيل |
|-------|----------|
| الوصف | تسجيل الانصراف عند الضغط على زر الخروج |
| الخطوات | 1. سجّل دخول كموظف 2. اضغط «تسجيل الخروج» 3. تحقق من تقرير الحضور |
| البيانات المطلوبة | حساب موظف |
| النتيجة المتوقعة | يُسجّل وقت الانصراف بشكل صحيح |
| الأولوية | عالية |

### TC-ATT-010: تقرير الحضور

| البند | التفاصيل |
|-------|----------|
| الوصف | عرض تقرير الحضور والانصراف |
| الخطوات | 1. ادخل كمشرف 2. افتح `/Attendance/AttendanceReport` 3. اختر الشركة والموظف 4. حدد فترة زمنية 5. اضغط «عرض التقرير» |
| البيانات المطلوبة | بيانات حضور سابقة |
| النتيجة المتوقعة | يظهر تقرير بالأيام مع أوقات الحضور والانصراف وعدد الساعات |
| الأولوية | متوسطة |

### TC-ATT-011: عدم ظهور تنبيه للمشرف

| البند | التفاصيل |
|-------|----------|
| الوصف | التأكد أن نظام الحضور لا يعمل لحساب المشرف |
| الخطوات | 1. سجّل دخول كمشرف 2. انتظر 30+ دقيقة |
| البيانات المطلوبة | حساب مشرف |
| النتيجة المتوقعة | لا تظهر نافذة تنبيه عدم النشاط |
| الأولوية | متوسطة |

## الحالات الحدية

- ماذا لو فقد الاتصال بالإنترنت أثناء إرسال النبض؟
- ماذا لو فتح الموظف البرنامج في تبويبين — هل يتم تسجيل حضورين؟
- ماذا لو أعاد الموظف تحميل الصفحة (F5) — هل يفقد الحضور؟
- ماذا لو نام الجهاز (Sleep) ثم عاد — هل يتم التنبيه مباشرة؟
