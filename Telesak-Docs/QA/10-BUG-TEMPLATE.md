# نموذج تقرير الأخطاء (Bug Report Template)

## كيفية الاستخدام

عند اكتشاف خطأ (Bug)، انسخ هذا النموذج وعبّئه بالكامل ثم أرسله للفريق التقني.

## مثال مُعبّأ

```
رقم الخطأ:      BUG-001
التاريخ:         2026/03/25
المُبلغ:         أحمد محمد
الأولوية:        [✓] عالية
الحالة:          [✓] جديد

وصف الخطأ:
عند محاولة رفع ملف PDF على مهمة جارية، تظهر رسالة خطأ
"حدث خطأ غير متوقع" ولا يتم رفع الملف.

خطوات إعادة الإنتاج:
1. سجّل دخول كموظف
2. افتح مهمة بحالة «جاري العمل»
3. اضغط «المرفقات»
4. اختر ملف PDF (حجمه 2MB)
5. اضغط «ارفع الملف»

النتيجة الفعلية:
تظهر رسالة: "حدث خطأ غير متوقع" والملف لم يُرفع

النتيجة المتوقعة:
يجب أن يُرفع الملف ويظهر في قائمة المرفقات

الصفحة:         /Employee/Tasks/TaskDetails?id=abc123
نوع المستخدم:   [✓] موظف

المتصفح:        [✓] Chrome
إصدار المتصفح:  123.0.6312.86
الجهاز:          [✓] كمبيوتر
نظام التشغيل:   [✓] Windows 11
دقة الشاشة:     1920×1080

صورة الشاشة:    [✓] مرفقة (screenshot-bug001.png)
```

## تصنيف الأولوية

| الأولوية | الوصف | أمثلة |
|----------|-------|-------|
| **حرجة** | النظام لا يعمل / بيانات تُفقد | لا يمكن تسجيل الدخول، المهام تُحذف عشوائياً |
| **عالية** | ميزة أساسية لا تعمل | لا يمكن قبول المهام، لا يمكن رفع ملفات |
| **متوسطة** | ميزة تعمل لكن بشكل غير صحيح | الفلتر لا يُصفّي بشكل صحيح، التاريخ يظهر خطأ |
| **منخفضة** | مشكلة شكلية أو تجميلية | خط صغير، لون غير متناسق، ترتيب غير مثالي |
