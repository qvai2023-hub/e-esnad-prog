## 1. المتطلبات المسبقة

| البند | القيمة | ملاحظات |
|-------|--------|---------|
| حساب اختبار (موظف) | موجود ونشط | يجب أن يكون `isCompany = false` |
| متصفح | Chrome أو Edge | **إلزامي** — Firefox/Safari تجريبي |
| DB Migration | مُنفّذ | `AddLastHeartbeat.sql` مُشغّل على قاعدة البيانات |
| AutoCheckoutJob | يعمل | يبدأ تلقائياً مع `Application_Start` |
| JS Tracker | مُحمل | يظهر في `<script src="~/Scripts/attendance-tracker.js">` في المصدر |

**فحص سريع قبل الاختبار:**
1. افتح `Developer Tools (F12)` → Console
2. سجّل دخول كموظف
3. ابحث عن رسالة: `[AttendanceTracker] Initialized with attendance ID: X`
4. إن لم تظهر → المشكلة في `attendance-tracker.js` أو `GetCurrentAttendance`

## 2. ملخص المكونات

### المكونات الـ 3 للنظام

```
┌─────────────────────────────────────────────┐
│  الطبقة 1: sendBeacon (إغلاق المتصفح)      │  ← ~80% من الحالات
│  الطبقة 2: تنبيه عدم النشاط (الخمول)          │  ← ~10% من الحالات
│  الطبقة 3: وظيفة الخادم (AutoCheckoutJob)   │  ← ~5% من الحالات (شبكة/إغلاق مفاجئ)
└─────────────────────────────────────────────┘
```

### الجدول الزمني

| الحدث | التوقيت | الفعل |
|-------|---------|-------|
| تسجيل الدخول | دقيقة 0 | تسجيل الحضور التلقائي + `LastHeartbeat = now` |
| النبض | كل 60 ثانية | `POST /Attendance/LogActivity` → تحديث `LastHeartbeat` |
| عدم النشاط | 30 دقيقة | ظهور نافذة التنبيه مع عدّاد 5:00 |
| تنفيذ العدّاد | 5 دقائق بعد التنبيه | إذا لم يستجب → انصراف تلقائي |
| وظيفة الخادم | كل 15 دقيقة | إغلاق السجلات المُهملة (LastHeartbeat > 15 دقيقة) |

## 3. حالات الاختبار — تسجيل الدخول والحضور التلقائي

### TC-ATT-001: تسجيل حضور تلقائي عند الدخول

| البند | التفاصيل |
|-------|----------|
| **الهدف** | التحقق من إنشاء سجل حضور تلقائي عند تسجيل دخول الموظف |
| **الخطوات** | 1. سجّل دخول كموظف <br> 2. افتح `Developer Tools` → Console <br> 3. تحقق من رسالة `[AttendanceTracker] Initialized with attendance ID: X` <br> 4. افتح قاعدة البيانات أو تقرير الحضور |
| **البيانات المطلوبة** | حساب موظف نشط |
| **النتيجة المتوقعة** | - سجل جديد في `Attendance` مع `CheckIn = الآن` <br> - `LastHeartbeat` = وقت تسجيل الدخول <br> - رسالة `[AttendanceTracker] Initialized...` في Console |
| **الأولوية** | حرجة (Critical) |

### TC-ATT-002: عدم تسجيل حضور للمشرف (Company)

| البند | التفاصيل |
|-------|----------|
| **الهدف** | التحقق من أن المشرف لا يحصل على سجل حضور |
| **الخطوات** | 1. سجّل دخول كمشرف (Company) <br> 2. افتح Console <br> 3. تحقق من عدم وجود رسالة `[AttendanceTracker] Initialized...` |
| **النتيجة المتوقعة** | - لا تظهر رسالة tracker <br> - لا يُنشأ سجل في `Attendance` <br> - `GetCurrentAttendance` يُرجع `hasAttendance: false` |
| **الأولوية** | عالية |

### TC-ATT-003: عدم تسجيل حضور مزدوج لنفس اليوم

| البند | التفاصيل |
|-------|----------|
| **الهدف** | التحقق من عدم إنشاء سجل جديد إذا كان سجل اليوم مفتوحاً |
| **الخطوات** | 1. سجّل دخول كموظف (يُنشأ سجل حضور) <br> 2. سجّل خروج يدوياً <br> 3. سجّل دخول مرة أخرى (نفس اليوم) <br> 4. تحقق من سجلات `Attendance` للموظف |
| **النتيجة المتوقعة** | - يُنشأ سجل **جديد** ثانٍ (لأن الأول أُغلق) <br> - لا يُعدّل السجل الأول المغلق |
| **الأولوية** | عالية |

| **الخطوات** | 1. سجّل دخول كموظف <br> 2. تفاعل مع الصفحة (أو اتركها — النبض يستمر) <br> 3. انتظر 15 دقيقة <br> 4. تحقق من DB |
| **النتيجة المتوقعة** | - `CheckOut IS NULL` <br> - `LastHeartbeat` حديث (< 15 دقيقة) <br> - AutoCheckoutJob لا يُغلق السجل |

| **النتيجة المتوقعة** | - AutoCheckoutJob يبدأ تلقائياً مع `Application_Start` <br> - السجل المُهمل يُغلق في أول دورة (بعد 15 دقيقة) |
| **الأولوية** | متوسطة |

## 12. أدوات الاختبار

### تسريع الاختبار (Console Commands)

افتح `Developer Tools (F12)` → Console وأكتب:

```javascript
// تسريع التنبيه إلى 10 ثوانٍ (بدلاً من 30 دقيقة)
AttendanceTracker.setConfig({INACTIVITY_WARNING: 10000});

// تسريع التنبيه + تقليل العدّاد إلى 5 ثوانٍ (بدلاً من 5 دقائق)
AttendanceTracker.setConfig({INACTIVITY_WARNING: 10000, INACTIVITY_TIMEOUT: 5000});
```

### استعلامات SQL للتحقق

```sql
-- آخر سجل حضور للموظف X
SELECT TOP 5 Id, EmpId, CheckIn, CheckOut, LastHeartbeat, AutoCheckout
FROM Attendance
WHERE EmpId = [X]
ORDER BY Id DESC;

-- سجلات مفتوحة (غير مُغلقة)
SELECT Id, EmpId, CheckIn, DATEDIFF(MINUTE, LastHeartbeat, GETDATE()) AS MinutesSinceLastHeartbeat
FROM Attendance
WHERE CheckOut IS NULL;

-- سجلات أُغلقت تلقائياً (اليوم)
SELECT * FROM Attendance
WHERE AutoCheckout = 1 AND CAST(CheckIn AS DATE) = CAST(GETDATE() AS DATE);
```

## ملاحظات للمختبِر

1. **استخدم Chrome** — Firefox/Safari قد لا يدعم `sendBeacon` بشكل كامل.
2. **لا تغلق Console** أثناء الاختبار — الرسائل تفيد في التشخيص.
3. **الاختبار الحقيقي يحتاج 30+ دقيقة** — استخدم `setConfig()` لتسريع الاختبار.
4. **تأكد من DB Migration** قبل الاختبار — `LastHeartbeat` و `AutoCheckout` يجب أن تكون موجودة.
5. **AutoCheckoutJob يعمل كل 15 دقيقة** — السجل المُهمل يُغلق في أول دورة بعد 15 دقيقة.
6. **عبور منتصف الليل** — يحتاج اختباراً يدوياً أو بأتمتة على بيئة التطوير.
